# Posetiivi v5 — suunnitelma

Tavoite: perusposetiivi joka pyörii Pi 5:llä (2 Gt) nyt ja jatkossa,
kuulostaa genreltään (tango on tangoa), ja jonka kappaleilla on aidon
kansansävelmän muoto. Space-posetiivi on rajattu ulos toistaiseksi.

## Periaatteet (sovittu 2026-07-21)

1. **Hybridi**: neuroverkko sinne missä *keksiminen* ratkaisee (melodia,
   fraseeraus), säännöt/Markov sinne missä *rakenne tai luotettavuus*
   ratkaisee (muoto, kadenssit, tahtilaji), kovakoodaus lukkoihin.
   Jokainen uusi ominaisuus arvioidaan tätä vasten: halvin työkalu joka
   tekee työn luotettavasti.
2. **Genre on kytkin, ei liuku**: yksi genre kerrallaan, ja se valitsee
   genrekohtaisen spesialistimallin. Reititys on eksplisiittinen sääntö
   (vipu → malli), ei opittu portti (ei neuraali-MoE:ta — 11 M:n
   mittakaavassa siitä ei ole hyötyä, vain läpinäkymättömyyttä).
3. **Jatkuvat vivut ovat tunnelmaa**: valence, energia, tiheys, rekisteri
   — genren *sisällä*, kaikille genreille samat. CFG terävöittää näitä.
4. **Treeni on ilmaista** (yöajot M4 Maxilla), **data on pullonkaula**.
   Vaiva datankeräysputkiin, ei laskennan säästöön. Iterointi: treenaa
   yön yli → korvatesti + mittarit → säädä → uusi yö.
5. **RAM ei rajoita mallikirjastoa**: levyllä rajaton määrä genremalleja
   (42 Mt/kpl), muistissa vain aktiivinen (+ pieni LRU). Genren lisäys =
   tiedosto + rivi valitsimeen.

## Arkkitehtuuri

```
                    ┌─ SÄÄNTÖTELINE (muoto, kadenssit, tahtilaji) ─┐
genre-kytkin ──────►│  ┌────────────────────────────────────────┐  │
                    │  │ genrekohtainen malli (esim. tango.pt)  │  │
tunnelmavivut ─────►│  │ cond = 6 floatia, FiLM + CFG           │  │
                    │  └────────────────────────────────────────┘  │
kampi ─────────────►│  MIDI-kello (ennallaan)                      │
                    └──────────────────────────────────────────────┘
```

### 1. Rakenneteline (uusi, korjaa mitatun puutteen)

Mitattu v4:llä: fraasitoisto lag-8 on 0.37 vs. aitojen 0.47 — A-osa ei
palaa tunnistettavana. Ratkaisu ei ole isompi malli vaan pakotettu muoto:

- Fraasi = 8 tahtia. Muototemplaatti arvotaan sävelmäpituudesta
  (nykyinen aitojen jakauma): 32 → AABB, 48 → AABBCC, 64 → AABBCCDD.
- Malli **generoi** A:n (8 tahtia); teline **toistaa** sen ajamalla A:n
  tokenit uudelleen KV-cacheen (prime, ei samplausta — halpaa ja
  nuotilleen uskollista). Kertauksen viimeinen tahti generoidaan
  uudelleen etenemä-ehdolla (1. ja 2. maali, kuten aidoissa).
- B generoidaan neuraalisti A:n konteksti muistissa; sama toisto.
- Looppivahti pysyy fraasien sisällä; "uusi kappale" -nappi hyppää
  telineessä loppukadenssiin.
- **Pi-bonus**: neuraalisamplaus ajetaan vain uudelle materiaalille
  (~50 % tahdeista AABB:ssä) → laskentabudjetti puolittuu.
- Myöhempi vipu: kertauksen uskollisuus (kirjaimellinen ↔ matalalämpö-
  variaatio). v5:ssä kirjaimellinen + 2. maali riittää.

### 2. Genrespesialistit

- **Perusmalli**: koko aineisto, EI genre-ulottuvuuksia condissa.
  Oppii melodisen selkärangan ja tunnelma-akselit.
- **Genremallit**: hienosäätö perusmallista (train.py --init on jo
  olemassa) genren omalla datalla. Tahtilaji tulee genrestä
  (GENRE_METER), joten spesialistin ei tarvitse edes valita sitä.
- **Koe koossa**: spesialistille kapeampi jakauma voi riittää 4×256
  (3,2 M param) → ~3× kevyempi inferenssi Pi:llä kuin 6×384. Mitataan
  molemmat samalla datalla, korva + mittarit päättävät.
- cond kutistuu: [valence, energia, tiheys, rekisteri, fraasi, etenemä]
  = 6 floatia (oli 23). Condition dropout ja CFG ennallaan.

### 3. Soittimen mallirekisteri

- `models/<genre>.pt` levyllä; `ModelRegistry` lataa valitun (~alle
  sekunti), vaihto astuu voimaan sävelmärajalla — ei katkoa.
- LRU-välimuisti 2 mallille (RAM sallii; pomppiminen välitöntä).
- Mallit päivittyvät itsenäisesti: parempi tango.pt tilalle koskematta
  muihin.

### 4. UI

- Tyylilajivivut → **valitsin** (radio, yksi päällä).
- Tunnelmapaneeli: valence, energia (uusi vipu), tiheys (uusi vipu,
  eriytetään kammen densitystä: kampi antaa pohjan, vipu biasoi),
  rekisteri. Autoplay, Uusi kappale ja veivi ennallaan.

## Data (pullonkaula — tähän vaiva)

Nykytila: valssi 3946, polkka 4208, marssi 1804, masurkka 582 sävelmää;
muut 13 genreä = 0. Kynnys spesialistille: **≥ 300 siivottua sävelmää**
(masurkka 582 toimii; alle sen ei julkaista kytkintä).

Järjestys (putki ensin sinne missä data on rakenteisinta):

1. **FolkWiki** (folkwiki.se, ABC + sävelmätyypit — sama muoti kuin The
   Session): polska, jenkka, suomalainen polkka/valssi. Nouturi
   `fetch_folkwiki.py` samaan malliin kuin `fetch_thesession.py`.
2. **Tango**: MIDI-arkistot (todotango ym.) — vaatii enemmän siivousta
   (moniraitaiset sovitukset → melodia+säestys-erottelu).
3. **Musette / sirkus / klezmer**: MIDI-kokoelmat + Mutopia; sama
   siivousputki. Julkaistaan sitä mukaa kun 300 ylittyy.

Siivousputki (uusi `training/clean_midi.py` tarvitaan tangoa varten):
tahtilajisuodatus, melodiaraidan tunnistus (korkein tiheä ääni),
kvantisointi, kesto 8–256 tahtia — sitten normaali prepare_data.

## Treeniresepti (yöjonot)

```bash
# 1) perusmalli (kerran per datapäivitys)
python train.py --data data/prepared_v5 --out models/base \
    --layers 6 --dim 384 --steps 12000 --batch 8       # ~5,5 h M4 Max
# 2) genremallit jonossa (cron/skripti train_queue.sh)
python train.py --data data/prepared_v5_valssi --out models/valssi \
    --init models/base/best.pt --lr 1e-4 --steps 3000   # ~1,5 h/genre
```

M4 Max -reunaehdot (opittu): batch 8 @ seq 4096 on 36 Gt:n katto;
`memory_pressure -Q` ennen starttia; `python -u` + `caffeinate`.
Yhteen yöhön mahtuu perusmalli TAI ~4-6 genrehienosäätöä.

## Mittarit ja portit (ennen julkaisua kytkimeen)

`training/evaluate.py` (uusi — sessiossa 07-21 tehdyt analyysit
pysyväksi työkaluksi): fraasitoisto lag-8, A/B-kontrasti,
naapuritahtitoisto (v3: 14 % vs. aito 1 % — mittaamatta v4:llä!),
pituusjakauma, tyhjätahtiosuus, tiheys vs. genren aito data.

Portti genremallille: lag-8 ±0.10 aidosta, naapuritoisto < 5 %,
tyhjiä tahteja < 1 % guidance 4.0:lla, + korvatesti.

Pytest-minimi (nyt 0 testiä): tokenisoinnin edestakaisuus, KV-cachen
logiittiekvivalenssi, säveltäjärajapinta (nuotit, iskua), telineen
muototilakone, ModelRegistryn vaihto sävelmärajalla.

## Pi-vienti

- **Vaihe 0** (ennen rautaa): config.tomliin `[llm] cache_len` (oletus
  1536, säästää ~50 Mt), `torch_threads = 4`; karsittu soundfont
  (posetiivin 6 soundia täydestä GM:stä, ~142 Mt → muutama Mt).
- **Vaihe 1**: Pi 4 1GB -koe (hankittu): mittaa ms/tahti torch-CPU:lla.
  Tulos erottelee: pysyy tahdissa → kaikki helppoa; RAM loppuu → trimmit
  riittävät; CPU ei riitä → vaihe 2.
- **Vaihe 2** (vain jos tarpeen tai halutaan marginaalia): ONNX Runtime
  + int8-dynaaminen kvantisointi (1,5–3× ARM:lla). Rakenneteline
  puolittaa kuorman jo sitä ennen.
- **Kohde**: Pi 5 2GB + aktiivijäähy. Sama A76 kuin isommissa; 2 Gt
  riittää (soitin ~250 Mt trimmattuna, yksi malli kerrallaan).
- systemd-yksikkö on repossa; GPIO-kampi evdevillä kuten nyt.

| # | Mitä | Riippuu | Tulos |

| M1 | Rakenneteline + evaluate.py + pytest-minimi | — | lag-8 kuntoon ilman treeniä; Pi-kuorma −50 % |
| M2 | v5-perusmalli (6-dim cond) + naapuritoiston uusintamittaus | M1:n mittarit | yksi yöajo |

## Riskit ja varasuunnitelmat

- **Kirjaimellinen kertaus kuulostaa konemaiselta** → uskollisuusvipu
  (matalalämpövariaatio); pahimmillaan teline vain *biasoi* toistoa
  logiteissa pakottamisen sijaan.
- **Hienosäätö unohtaa selkärangan** (catastrophic forgetting) →
  pienempi lr, varhainen pysäytys mittariportilla; varalla adapterit
  (deltapainot), jotka sovittiin pidettäväksi takataskussa.
- **Tango-MIDIen siivous osoittautuu työlääksi** → FolkWiki ensin
  (rakenteinen ABC), tango vasta putken kypsyttyä.
- **Pi 4 -koe paljastaa CPU-vajeen** → ei kaada mitään: kohde on Pi 5,
  ja ONNX/int8 + teline antavat yhdessä ~3–6× marginaalin.

## Päätösloki (miksi näin)

- Genre-sekoitus hylätty: kategorinen ominaisuus + diskreetti tahtilaji
  eivät interpoloidu; sekoitusvivut olivat 13/17 genrelle kohinaa.
  Tunnelma-akselit ovat aidosti jatkuvia ja analyyttisesti labeloituja
  (features.py laskee ilmaiseksi) → CFG:n oikea käyttökohde.
- Neuraali-MoE hylätty: hyöty syntyy vasta mittakaavassa jota meillä ei
  ole; opittu reititys hämärtäisi sen minkä genre-kytkin jo kertoo.
- Täydet genremallit > adapterit: treeni on ilmaista (yöt), RAM riittää
  yhdelle kerrallaan, laatu ja yksinkertaisuus voittavat.
- Rakenneteline > isompi malli: mitattu puute on muodossa, ei
  melodiassa; sääntö korjaa sen ilmaiseksi ja keventää Pi-kuormaa.
